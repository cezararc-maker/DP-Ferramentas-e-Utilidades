# Plano de entregas

## Versão 0.1 — Base funcional

- Interface desktop e catálogo configurável.
- Pesquisa e categorias.
- Fluxo integrado FGTS Poligonal.
- Abertura das ferramentas e documentação.
- Logs locais e rotina de build.

## Versão 0.2 — Integração e diagnóstico

- Tela para editar caminhos sem alterar JSON.
- Indicador de versão dos projetos locais.
- Diagnóstico de dependências e atalhos ausentes.
- Painel de logs dentro do aplicativo.

## Versão 1.0 — Distribuição

- Instalador Windows com atalho no menu Iniciar.
- Atualização controlada a partir de versões publicadas no GitHub.
- Backup e restauração das configurações locais.
