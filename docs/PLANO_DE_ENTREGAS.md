# Plano de entregas

## Versão 0.1 - Base funcional

- Interface desktop e catálogo configurável.
- Pesquisa e categorias.
- Fluxo integrado FGTS Poligonal.
- Abertura das ferramentas e documentação.
- Logs locais e rotina de build.

## Versão 0.2 - Interface e fluxo

- Ajustes visuais da marca.
- Fluxo FGTS tratado como sugestão expansível.
- Rolagem da página inicial.
- Tema claro/escuro.
- Execução sem manter console CMD aberto.

## Versão 0.3 - Painel de projetos

- Área própria `Projetos`.
- Estados oficiais: Ativo, Bloqueado, Pausado, Planejado e Finalizado.
- Progresso estimado por projeto.
- Última atualização e leitura do último commit Git local quando disponível.
- Bloqueio atual, próxima tarefa e dependências.
- Botões para abrir pasta do projeto, GitHub e execução.
- Catálogo de projetos separado do catálogo de ferramentas.

## Próximas versões

- Tela para editar caminhos e dados sem alterar JSON.
- Diagnóstico de dependências e atalhos ausentes.
- Painel de logs dentro do aplicativo.
- Sincronização opcional de metadados dos projetos a partir do GitHub.

## Versão 1.0 - Distribuição

- Instalador Windows com atalho no menu Iniciar.
- Atualização controlada a partir de versões publicadas no GitHub.
- Backup e restauração das configurações locais.
